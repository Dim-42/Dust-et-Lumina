# Current system-message classes

<p class="system-msg">SYSTEM MESSAGE: ordinary operational status.</p>
<p class="system-msg-note">SYSTEM NOTE: supplemental implementation context.</p>
<p class="system-msg-warning">SYSTEM WARNING: intentional fixture, not canonical content.</p>

The swatches are deliberately represented by current text classes rather than new color-token markup. This reveals the production treatment actually available to authors.
